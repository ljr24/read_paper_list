## 状态约定

- **候选阅读**：仅进入推荐或获奖清单，尚未确认开始阅读。
- **进度待补充**：已确认为阅读条目，尚未记录读到哪里。
- **阅读中 / 已讨论**：记录已读章节、讨论问题或笔记链接。
- **已读完**：明确完成全文阅读后再标记。

收录、获奖及有项目主页均不代表已读完。当前没有把任何条目标为“已读完”。

## 维护方式

1. 新论文加到对应清单；保留原文标题、会议或预印本年份、论文与项目链接。
2. 阅读后更新状态，并用一句话记录读到的章节或关键问题；长笔记另建文件并链接。
3. 奖项只依据会议官方名单记录，区分 Best Paper、Honorable Mention 与专项奖。
4. 未确认的信息写“待补充”或“未核实”，不猜测会议、奖项或阅读完成情况。
